# 🛸 德清低空三维网格航路规划与冲突检测服务 (Deqing Serve)

> **最后更新时间**：2026年9月16日

德清低空三维网格服务（`deqing_serve`）是基于 **C++20** 与 **Drogon Web 框架** 构建的高性能低空空域数字化、实景三维网格化、三维航路规划及实时时空冲突检测后端引擎。

系统以离散正交四叉格网（**DQG-3D**）为空间数据底座，深度融合 **PostgreSQL/PostGIS** 空间矢量图层、**Redis** 高并发时空环境缓存与 **GDAL/GeoTIFF** 真实地形高程，为低空无人机飞行提供高精度网格计算、三维球形安全缓冲、空间障碍绕飞与多维时空约束下的智能航路规划服务。

## 2. 核心业务能力

1. **高精度三维空间网格化**：
   - 0~21 层级 DQG-3D 网格编解码、中心点、包围盒、父子关系解析；
   - 点、点缓冲区、折线、多边形（含带洞多边形）、矩形缓冲区空间体素网格化；
   - 独创 **八叉树自底向上多尺度聚合（`aggregateToMultiScaleCodes`）**，将 8 个满子网格归纳为 1 个父网格，极大降低网格传输量。
2. **倾斜摄影实景三维（OSGB）快速体素化入库**：
   - 自动识别 OSGB 分块目录（`Block_*`, `Tile_*`）并行提取三角面片；
   - 自动解析 `metadata.xml` 进行局部投影坐标转换；
   - **越界三角面片边界过滤**（杜绝无符号整型下溢），支持 1000 条/批的高速入库与日志持久化。
3. **自适应尺寸球形缓冲区的 3D A* 航路规划**：
   - 支持无人机物理半径 `planeRadius` 自适应生成 3D 掩码，提供保底一格物理间隔；
   - **仿地贴地飞行**：航路点自动按真实地面高度叠加作业真高（`workHeight`）；
   - **起降垂直段构建**：自动生成起飞上升段与降落垂直段，并进行准确阶段标识；
   - **PostgreSQL 活动可见图水平绕障**：遇到永久/临时禁飞区时，自动在水平面插入二维绕行必经点；
   - **全链路航路统一校验**：A* 搜索与贪婪抽稀（`SmoothAstarPathPlane`）共用底层校验规则，消除抽稀复检误杀。
4. **多维时空冲突与规则评估引擎**：
   - 支持动态传入微气象、信号、电磁、风险区、隐私区等多因子权重与阶梯代价；
   - 支持 **`threshold` 极端阈值硬阻断**（如风速大于阈值直接拒绝通行）；
   - 航线全量冲突检测（`/lineConflict/check`）与首个冲突快速熔断（`/lineConflict/checkFirst`）。

## 4. 核心系统机制

### 4.1 3D 球形缓冲区与尺寸自适应

系统根据无人机物理外轮廓半径 `planeRadius`（单位：米，默认 0.75m）与当前层级网格物理尺寸 `gridSize` 动态生成三维球体膨胀掩码（`sphericalMask`）：

$$\text{extendCell} = \left\lceil \frac{\text{planeRadius}}{\text{gridSize}} \right\rceil$$

- **空间距离精确判定**：对 $\Delta x, \Delta y, \Delta z \in [-\text{extendCell}, \text{extendCell}]$，只有当物理距离 $\sqrt{\Delta x^2 + \Delta y^2 + \Delta z^2} \times \text{gridSize} \le \text{planeRadius}$ 时才纳入缓冲集。
- **保底一格安全缓冲**：若 `planeRadius > 0.0` 但计算出的掩码仅有中心自身（小机型），系统强制扩展至周围 26 个邻居，确保机身至少与障碍物相隔一个完整网格。
- **全系统一致性**：该掩码在 A* 邻居搜索、抽稀段复检（`thinPathGreedy`）、线段冲突检测中全面复用。

详细机制见：👉 [A星路径规划缓冲区机制说明.md](./A星路径规划缓冲区机制说明.md)

### 4.2 航路统一线段校验与平滑抽稀

为解决传统寻路中“A* 生成了折线，但抽稀时因判定条件不一致导致抽稀失败或直接坠毁”的矛盾，系统重构了统一线段校验函数（`validateSegmentsShared`）：

1. **时空连续积分**：按飞行速度 `speed` 前向累加飞行用时，精准计算每个被穿越网格的进入与离开时刻（精确到秒），准确关联带时间窗口的动态环境与临时围栏。
2. **真高中心线校验**：若启用 `enableTrueHeightCheck`，中心航迹经过的网格必须满足距离地表 DEM $15\text{m} \sim 120\text{m}$ 的真高限制，缓冲层不放大高度检查。
3. **软代价不劣性比较**：抽稀替代原有原子折线的前提不仅是“无碰撞”，且快捷直线的综合风险软代价不能劣于原折线路径。

统一线段校验机制已与 3D 球形缓冲区深度结合，详见：👉 [A星路径规划缓冲区机制说明.md](./A星路径规划缓冲区机制说明.md)

### 4.3 PostgreSQL 二维活动可见图绕障

针对大范围城市禁飞区（`air_space`）、固定电子围栏（`fence`）、地面风险区（`risk_area`）以及具备特定时间窗口的临时围栏（`temporary fence`），系统引入了基于数据库的**活动可见图（Visibility Graph）预处理机制**：

- 在 3D A* 启动前，先在二维投影平面通过可见图算法求得绕过所有二维硬障碍的最优折线；
- 将绕行折点作为中间途径点动态插入（前端原生点标记为 `mustPass = true`，绕障点标记为 `mustPass = false`）；
- 抽稀阶段严格锁定在 `mustPass` 必经点之间分段抽稀，确保绕障路径不会被视线穿透误直连。

### 4.4 算路规则引擎与阈值硬阻断

系统在 A* 与冲突检测中使用动态规则评估引擎（`GridEvaluator`）：

- **废除 `defaultValue`**：历史版本中的 `defaultValue` 已完全移除。Redis 查无数据或未命中任何配置区间时，默认追加代价为 `0.0`。
- **极端阈值硬阻断（`threshold`）**：支持在规则中配置极端阈值表达式（如 `">13.8"`、`"<10 || >40"`）。一旦某网格监测值命中阈值，无论权重多小，**该网格直接判定为不可通行（Hard Block）**，实现防大风、防暴雨、防极温的硬隔离。
- **权重模式**：支持 `shortest`（最短路径）、`safest`（安全极化）、`balanced`（均衡最优）以及 `original`（原始无代价 A*）四种宏观模式。

详细因子字典与示例见：👉 [多权重算路.md](./多权重算路.md)

### 4.5 多尺度网格自底向上聚合

在 `/api/multiSource/geometricGrid/getGridByPolygonAndHeight` 等接口中支持 `aggregate=true`：

- 底层调用 `dqglib` 的 `aggregateToMultiScaleCodes`；
- 从最细层级自底向上扫描，当发现属于同一个父节点的 8 个空间子网格全部存在时，合并折叠为 1 个父网格；
- 递归合并直到达到指定的 `minLevel` 或无满足 8 个子格的节点，可缩减 70%~90% 的网格数据传输量。

详细接口见：👉 [dqglib函数接口文档.md](./dqglib函数接口文档.md)

## 5. 配置文件说明

服务启动依赖 4 个核心文件：

1. **`region.json`**：定义低空作业区的经纬度四至边界（`southwest`, `northwest`, `northeast`, `southeast`）及高程基准范围（`bottom`, `top`）。系统启动时必须成功初始化全局基准瓦片（`BaseTile`）。
2. **`config.json`**：Drogon 框架核心配置，包含监听端口（`9997`）、PostgreSQL 连接池（`db_clients`）、Redis 连接池（`redis_clients`）以及自定义项（如 `tiff_file_path`, `pg_table_name`）。
3. **`weight.json`**：预设寻路模式（`modes`）的各因子权重及各环境因素（`dc`, `tx`, `dh`, `jk`, `fxq_11`, `privacy`, `wdh`, `wdd`）的分段阶梯代价与阈值。
4. **`dem.tif`**：高精度数字高程模型（GeoTIFF），用于计算地面真实海拔以实现仿地贴地与防撞地真高校验。
